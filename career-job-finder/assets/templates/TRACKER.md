# Application tracker

Record roles by employer and requisition when available. Link the existing row for overlaps. Current employer evidence, draft work and candidate outcomes are separate observations.

| Employer / role / ID | Official URL and last source check | Fit or material limit | State and evidence/date | Role folder and current version | Next step |
|---|---|---|---|---|---|

Useful states include Research, Held, Local draft, Review ready, Entered, Saved draft verified, Approved for named action, Submission attempt pending confirmation, Submission outcome unknown, Submitted confirmed, Interview scheduled and Final outcome. Label candidate reports as such and keep prior evidence. Application state and approval scope may require separate entries.

Keep supporting files in one role folder per role. Save the reviewed role packet and action record using ROLE-REVIEW.md. Do not store credentials there.
