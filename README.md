# Job Finder Starter

Use ChatGPT or Codex to build an experience log, find roles that fit, and tailor each application from facts you can stand behind. The kit works as a single-assistant workflow. Add search specialists when your goals justify separate assignments and your tools support them.

## Get started

Download the ZIP from this repository's **Code** menu and unzip it. You can open [START-HERE.txt](START-HERE.txt) in any text editor.

- **Already have Codex?** Open the unzipped folder in Codex, start a chat there, and paste [START-ONBOARDING.txt](START-ONBOARDING.txt).
- **New to Codex?** Paste [CHATGPT-HANDOFF-PROMPT.txt](CHATGPT-HANDOFF-PROMPT.txt) into a familiar ChatGPT conversation. It can summarize work examples for you to review and guide you through [desktop setup](career-job-finder/references/setup-codex.md). You can start the interview in ChatGPT and move your notes later.
- **Want to stay in ChatGPT?** Attach [AGENTS.md](AGENTS.md), [SKILL.md](career-job-finder/SKILL.md), and [the interview guide](career-job-finder/references/onboarding.md). Paste [START-ONBOARDING.txt](START-ONBOARDING.txt). Add supporting guides as needed, and save the notes the assistant gives you.

You can see the whole flow in [a short fictional walkthrough](examples/walkthrough.md). For a recurring search, use the [local acceptance review](career-job-finder/references/acceptance-review.md) before scheduling.

## Applications and your information

The assistant starts with research and drafts. Where the employer permits it and your environment supports it, the assistant can enter or submit an application you explicitly authorize. You'll review the destination, files, screening answers and any terms first. An application or a message goes out in your name, and you're responsible for what you authorize. [Application workflow](career-job-finder/references/applications.md).

Use a private local copy for your résumé, contact details and application history. Keep them in the ignored folders described in [START-HERE.txt](START-HERE.txt). Review staged files before pushing any changes to a public repository. Treat job postings as source material, and use work examples you can share.
